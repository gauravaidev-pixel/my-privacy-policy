Privacy Policy

Last updated: September 29, 2026

This Privacy Policy describes how NEET Motivation Bot ("the Application") handles information. The Application is a personal automation tool that uploads videos to YouTube using the YouTube Data API v3.

1. Personal Use Only

This application is for personal use only. It is not a commercial product and is not intended for public or third-party use.

2. No Data Collection

It does not collect, store, or share any user data.

3. Use of YouTube API

It only uses the YouTube API to upload videos to the owner's own channel. No other YouTube account is accessed, and no data from other channels is retrieved or processed.

4. No Third-Party Access

No third parties have access to user data. The Application does not sell, trade, or transfer any information to outside parties.

5. Data Retention

Since the Application does not collect or store any user data, there is no data retention policy required. OAuth tokens (if any) are stored securely on the owner's own device and are never shared.

6. Changes to This Policy

This Privacy Policy may be updated from time to time. Any changes will be reflected on this page with an updated "Last updated" date.
