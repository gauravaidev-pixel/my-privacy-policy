NEET Motivation Bot

A personal automation tool that uploads motivational videos to YouTube using the YouTube Data API v3.

About

This application is built for personal use to streamline uploading of motivational content to the owner's own YouTube channel. It leverages the official YouTube Data API v3 to publish videos.

Features

  • Automated video uploads to the owner's YouTube channel
  • Uses official YouTube Data API v3
  • Personal use only — no third-party data access
